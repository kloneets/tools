# Koko Tools Privacy Policy

Public HTML version for Google Play: https://koko.lv/koko-tools/privacy-policy.html

Last updated: July 17, 2026

Koko Tools stores notes, todos, and settings locally on your device. If you enable Firebase sync, that data is copied to the configured Firebase project so it can sync between your devices.

Koko Tools requests exclusion of its app-private Android data from Android cloud backup and device-to-device transfer. Device manufacturers and Android system components may control some migration behavior outside the app. Optional Firebase sync is separate from Android system backup and only runs if you enable it.

## Data The App Handles

- Account information: login email address and Firebase authentication identifiers.
- User content: workspace notes, todos, Pages values, and app settings.
- Sync metadata: workspace IDs, update timestamps, and device sync status.

Koko Tools does not include ads, in-app purchases, analytics SDKs, or crash reporting SDKs.

## Firebase Sync

Firebase sync is optional. When enabled, data is sent to Firebase over HTTPS and stored in the app's Firebase Realtime Database under your workspace. Google sign-in uses Firebase Authentication.

## Data Deletion

You can delete local app data by uninstalling the app. To request deletion of Firebase Authentication account data or synced workspace notes, todos, settings, and sync metadata, follow the instructions in [ACCOUNT_DELETION.md](ACCOUNT_DELETION.md).

Deleted account and workspace content is not retained after the deletion request is completed. Minimal correspondence and security audit records may be retained for up to 90 days when needed to process, verify, or document the request.
