# Koko Tools Privacy Policy

Public HTML version for Google Play: https://koko.lv/privacy-policy.html

Koko Tools stores notes, todos, and settings locally on your device. If you enable Firebase sync, that data is copied to the configured Firebase project so it can sync between your devices.

## Data The App Handles

- Account information: email address and Firebase authentication identifiers.
- User content: notes, todos, Pages values, and app settings.
- Sync metadata: workspace IDs, update timestamps, and device sync status.

Koko Tools does not include ads, in-app purchases, analytics SDKs, or crash reporting SDKs.

## Firebase Sync

Firebase sync is optional. When enabled, data is sent to Firebase over HTTPS and stored in the app's Firebase Realtime Database under your workspace. Google sign-in uses Firebase Authentication.

## Data Deletion

You can delete local app data by uninstalling the app. To request deletion of Firebase account data or synced workspace data, follow the instructions in [ACCOUNT_DELETION.md](ACCOUNT_DELETION.md).

## Contact

For privacy or deletion requests, open a GitHub issue in this repository using the account deletion instructions.
