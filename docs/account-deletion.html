Koko Tools Account And Data Deletion

Last updated: May 27, 2026

Koko Tools uses Firebase Authentication and Firebase Realtime Database when Firebase sync is enabled.

Request Cloud Account Or Data Deletion

To request deletion of your Firebase account data or synced workspace data, open a GitHub issue in the Koko Tools repository with the title Koko Tools account deletion request.

Include:

  • the email address used for Firebase login,
  • whether you want the Firebase account deleted, synced workspace data deleted, or both.

Do not include passwords, notes, todos, or other private content in the issue.

Local Android Data

Uninstalling the Android app removes local app-private data from the device.

Desktop Data

Desktop data is stored under the desktop app's local config directory and can be removed separately from your computer.

Privacy Policy

See the Koko Tools Privacy Policy.
