Koko Tools Privacy Policy

Last updated: May 27, 2026

Koko Tools is a productivity app for notes, todos, reading progress calculations, and optional Firebase sync.

Data Stored Locally

Koko Tools stores app data locally on your device, including:

  • notes,
  • todos,
  • Pages calculator values,
  • app settings and sync status.

Firebase Sync

Firebase sync is optional. If you enable Firebase sync, Koko Tools sends your synced app data to Firebase so it can be available across your devices.

Synced data may include notes, todos, shared app settings, workspace identifiers, update timestamps, and sync metadata.

Account Information

If you sign in with Firebase email/password or Google sign-in, Firebase Authentication handles your account. Koko Tools may store your email address, Firebase user identifier, workspace identifier, and authentication token metadata needed to keep sync working.

Data Sharing

Koko Tools does not sell your data. Koko Tools does not include ads, in-app purchases, analytics SDKs, or crash reporting SDKs.

When Firebase sync is enabled, data is processed by Firebase/Google services as required to provide authentication and sync.

Security

Network sync uses HTTPS. Authentication tokens are stored using Android system-provided encrypted storage where available. No storage or transmission method can be guaranteed to be perfectly secure.

Data Deletion

You can delete local Android app data by uninstalling the app. To request deletion of Firebase account data or synced workspace data, see the Koko Tools account and data deletion page.

Children

Koko Tools is not designed for children and is not intentionally directed to children.

Changes

This policy may be updated when app behavior or legal requirements change. The updated policy will be published at this URL.

Contact

For privacy or deletion requests, open an issue in the Koko Tools GitHub repository using the instructions on the data deletion page.
