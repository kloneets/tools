Koko Tools Privacy Policy

Last updated: July 17, 2026

Public URL: https://koko.lv/koko-tools/privacy-policy.html

Koko Tools is a productivity app for notes, todos, reading progress calculations, and optional Firebase sync.

Data Stored Locally

Koko Tools stores app data locally on your device, including:

  • notes,
  • todos,
  • Pages calculator values,
  • app settings and sync status metadata.

Koko Tools requests exclusion of its app-private Android data from Android cloud backup and device-to-device transfer. Device manufacturers and Android system components may control some migration behavior outside the app. Optional Firebase sync is separate from Android system backup and only runs if you enable it.

Firebase Sync

Firebase sync is optional. If you enable Firebase sync, Koko Tools sends your synced workspace data to Firebase so it can be available across your devices.

Synced data may include workspace notes, todos, shared app settings, workspace identifiers, update timestamps, and sync metadata.

Account Information

If you sign in with Firebase email/password or Google sign-in, Firebase Authentication handles your account. Koko Tools may store your login email address, Firebase user identifier, workspace identifier, and authentication token metadata needed to keep sync working.

Data Sharing

Koko Tools does not sell your data. Koko Tools does not include ads, in-app purchases, analytics SDKs, or crash reporting SDKs.

When Firebase sync is enabled, data is processed by Firebase/Google services as required to provide authentication and sync.

Security

Network sync uses HTTPS. Authentication tokens are stored using Android system-provided encrypted storage where available. No storage or transmission method can be guaranteed to be perfectly secure.

Data Deletion

You can delete local Android app data by uninstalling the app. To request deletion of Firebase Authentication account data or synced workspace notes, todos, settings, and sync metadata, see the Koko Tools account and data deletion page.

Deleted account and workspace content is not retained after the deletion request is completed. Minimal correspondence and security audit records may be retained for up to 90 days when needed to process, verify, or document the request.

Children

Koko Tools is not designed for children and is not intentionally directed to children.

Changes

This policy may be updated when app behavior or legal requirements change. The updated policy will be published at this URL.
